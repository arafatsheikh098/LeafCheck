Species the model can identify

The model is trained on BdLeaf20 — close-up photos of single leaves on plain backgrounds. Best results on similar photos.

    Want more species?

    The same pipeline can be retrained on any leaf-image dataset. The plan and the commands are in the project README under Roadmap: more species.

    1. Collect (or download) ~50+ photos per new species.
    2. Drop them into a folder, one subdirectory per species.
    3. Run python -m leafcheck.data prepare --source <folder> --out data/ then python -m leafcheck.train --config configs/bdleaf20.yaml — that's it, the same pipeline.
    This tool is a research preview. The model was trained on the BdLeaf20 leaf-image dataset (9 tropical plant species, single-leaf close-ups on plain backgrounds). It identifies plant species, not diseases. Real field photos will be less reliable. Always confirm with a botanist or local extension service before relying on the result for any decision.

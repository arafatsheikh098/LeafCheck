# examples/

Hand-picked placeholder images used by `scripts/smoke_test.sh` and the
G5 acceptance test.

These are **not** from PlantVillage. They are deliberately simple
coloured images generated by `scripts/_gen_examples.py` so the smoke
test can exercise the end-to-end API path without requiring a
54-image-per-class PlantVillage download.

The model was trained on the same synthetic distribution, so the
"expected class" listed in `labels.json` is what the smoke model
predicts — it is **not** a ground-truth plant-disease label.

In a production deployment, replace these 6 files with real
PlantVillage images (one per representative class) and update
`labels.json` with the real expected class for each.
